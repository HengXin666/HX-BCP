# 架构总览

## 一句话

三段正交能力, 各自可独立运行, 也可按需串成一条链路:

```text
            ┌──────────────┐   ┌───────────────┐   ┌────────────────┐
浏览器实例 ─┤ 缓存代理 8898 ├───┤ 上游代理 7890 ├───┤ 目标站点        │
            └──────────────┘   └───────────────┘   └────────────────┘
                   │                    │
                   └── 任一段都可省略 ───┘
```

## 组件职责

| 组件 | 端口 (默认) | 职责 | 不负责 |
|---|---|---|---|
| packages/browser | 8325 | 环境创建 / 启动 / CDP 接入 / 指纹派生 | 缓存, 出口 |
| packages/cache-proxy | 8898 | 静态资源缓存 (不终结 TLS) / 抓包 | 身份, 出口 |
| 上游代理 | 7890 | 出口 IP 与线路 | 身份, 缓存 |
| packages/fingerprint* | - | 指纹采集 / 判定 / 自检评分 | 会话生命周期 |
| apps/console-web | - | 人机两通道的操作界面 | 业务逻辑 |

## 关键约束

1. **不终结 TLS**: 缓存代理不改证书, 浏览器看到的连接语义不变。
2. **可拆可合**: 只用浏览器直连也成立; 只用缓存代理给别的工具也成立。
3. **判据唯一**: 端口、通道准入、环境可用性各只有一个实现。
4. **身份与出口分离**: 指纹环境决定"看起来像谁", 出口决定"从哪出去"; 二者可独立替换。

## 数据流

```text
创建环境 -> 启动实例 -> (可选) 挂缓存代理 -> (可选) 挂上游代理 -> 会话
                                     │
                               抓包 / 命中率 / 字节数
```

缓存代理只对可缓存静态资源生效; 动态请求原样透传, 命中统计与省流字节数可查询。

## 与外部工具的关系

- 浏览器可指向**任意** http / socks5 代理, 不要求是本仓库的上游代理。
- 缓存代理是一个普通 HTTP 代理, 任何支持代理的客户端都能接。
- 指纹自检可脱离浏览器单独对"某个已存在的环境"运行。
